# 05 Visualization Checks

The folder contains the script that creates a map that shows all EEA stations in Europe,
so we can observe the geographical spread of the stations. 

Run commands from the repository root.

```bash
python3 05_scripts_visual/plot_sensors_map_static.py
```

## Outputs

| Script | Output |
| --- | --- |
| `plot_sensors_map_static.py` | `Air_pollution_report/Figures/generated/sensors_map_static.png` |

## Input 

This script uses `pm_reference_stations_2024.csv` for the sensors on the map
