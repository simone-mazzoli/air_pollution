# Archive

This folder keeps older Sensor.Community modeling work from an earlier project
direction.

Sensor.Community data is crowd-sourced low-cost sensor data. The current
modeling pipeline in `06_models/` is instead based on official EEA/UBA reference
stations, fixed geographic folds, and the sealed northern/eastern Germany TEST
region.

The archived code is kept for history and reproducibility of the older work, but
it is not part of the current reference-station training, CV, final training, or
sealed TEST prediction workflow.

Do not use archived fold mappings or training scripts for the current ResNet and
CNN experiments.
